Changes in this version

This is a modified version of the original work. Changes made by Subham Mahesh:

  • Redesigned the user interface (viewer, popup and options page) with a calm, minimal look in light and dark mode.
  • Reduced the project to Firefox only; Chrome, Opera and online-demo builds were removed, as was support for Chrome, Edge and Opera extensions (CRX files and their stores).
  • Added this License & Credits page, with the licenses of all included open-source components.
  • The viewer shows files as a collapsible folder tree, like a file explorer.
  • Code is shown in a CodeMirror 6 editor (editing, search and replace, code folding, autocompletion, JSON checking); edited files can be downloaded alone or as a new zip.
  • A Changes panel lists edited files with added/removed line counts, shows each file's diff (inline or side by side) and can revert a single change, a whole file or everything.
  • All third-party libraries are installed from npm and bundled at build time: zip.js 2, js-beautify, strip-json-comments (instead of JSON.minify) and @noble/hashes (instead of SparkMD5).
  • New name (Zen Source Viewer), add-on ID and icon.

Each modified source file carries a notice saying it was modified by Subham Mahesh.
